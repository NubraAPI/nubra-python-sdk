# Security Policy

## Reporting A Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report security concerns privately by emailing:

- `support@nubra.io`

Include the following where possible:

- affected endpoint, SDK flow, or example path
- reproduction steps
- expected behavior and actual behavior
- impact assessment
- logs, screenshots, or request identifiers if available

We will review the report and coordinate next steps privately.

## Scope

This repository contains Nubra Python SDK examples and reference material.

Security-sensitive reports may include:

- authentication issues
- credential handling issues
- unintended live trading behavior
- order placement or cancellation flaws
- data exposure or permission bypass
