# Portfolio examples

Default environment is UAT. The API returns money in integer paise; these examples print rupees.

| File | What it does | Type |
| --- | --- | --- |
| `funds/basic_usage.py` | Funds and margin key figures | read-only |
| `holdings/basic_usage.py` | Holdings table with P&L and totals | read-only |
| `positions/basic_usage.py` | Positions table with P&L | read-only |
| `portfolio_summary.py` | Funds + holdings + positions in one summary (exposure, margin used) | read-only |
| `open_positions_pnl.py` | Open positions P&L table, worst first | read-only |
